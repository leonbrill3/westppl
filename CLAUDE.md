# West Ppl — project instructions

The West Ppl build is looking strong. The membership page and dashboard are the strongest parts of the product, and we want to keep moving in that direction.

However, we want to adjust the membership card positioning.

Important member card update:
Do not over-emphasize the physical metal card on the public membership page. The card is a nice brand element, but West Ppl should not feel like we are selling a card. The real product is access to a private community, curated events, member perks, concierge, local circles, and trusted people across Miami, LA, and NYC.

Please update the public /members page accordingly:

* Reduce or remove the large physical card showcase section.
* Keep “Member Card” or “Member Access Pass” as one of the perks, but make it more subtle.
* Position the member card as an access credential, not the main product.
* If you keep a visual card, make it smaller or more integrated into the dashboard/app concept.
* Prefer digital-first language unless a physical card is confirmed for launch.
* Avoid language that overpromises a physical metal card shipping immediately.

Suggested copy direction:
“Your West Ppl member pass unlocks events, perks, concierge access, and chapter benefits across Miami, LA, and New York.”

Alternative perk name:
“Member Access Pass” instead of “Metal Member Card.”

The main membership page should sell:

* invite-only community
* curated events
* member perks
* concierge
* local circles
* city chapters
* trusted network
* private member app

The card can remain as a detail, but the community is the product.

Next priorities:

Priority 1 — Fix obvious UX/data issues:

* Fix the blank CTA button at the bottom of the public Events page. It should say “Apply for Membership” or “Join West Ppl.”
* Fix the member card display so it never shows a broken-looking number like WP000000. For demo users, show a realistic sample like WP-000127, or show clean “Pending Activation” language.
* Fix dashboard mobile overflow, especially nav tabs, perk chips, and any horizontally clipped content.
* Improve admin mobile layout so application cards are readable and approve/reject buttons are not cramped.
* Remove or hide any visible dev/debug issue badges before launch.

Priority 2 — Improve the Home page:

* Keep the current dark editorial aesthetic, but make the hero clearer.
* The homepage should quickly communicate:
  “West Ppl is an invite-only members community across Miami, LA, and NYC with curated events, member perks, concierge, and a private member app.”
* Keep “sizzling souls” as brand flavor, but do not rely on it as the main explanation.
* Add clearer CTAs to Apply and Members/Login.
* Make the homepage feel connected to the membership product, not just a moody brand page.

Priority 3 — Reposition Marketplace:

* Do not build a full marketplace yet.
* For MVP, Marketplace should be a polished future-facing page for a trusted member marketplace.
* Shift the positioning away from only ultra-luxury services like private jets and expensive tailoring.
* Make it feel more like an elevated member-powered marketplace:

  * trusted services
  * local recommendations
  * member offers
  * event opportunities
  * wellness
  * dining
  * creative services
  * rentals
  * brand perks
  * concierge access
* Add “Coming Soon” or “Members-only marketplace launching soon” language if needed.

Priority 4 — Reposition Experiences:

* Keep the premium feel, but make Experiences feel less like a generic luxury travel agency.
* Make it closer to real West Ppl programming:

  * private dinners
  * music nights
  * art previews
  * wellness mornings
  * fashion week access
  * members trips
  * cultural events
  * Miami / LA / NYC chapter experiences
* Big destination trips can stay, but they should not dominate the page yet.

Priority 5 — Copy polish:

* Tighten copy across Home, Members, Apply, Login, Events, Experiences, Marketplace, and Dashboard.
* Voice should be elevated, concise, warm, and clear.
* Avoid overusing “sizzling souls.”
* Avoid implying features that are not built yet, like bookings, unless they are actually functional.
* Make the Apply page warmer and more community-focused.
* Consider adding one application question: “How would you like to contribute to the West Ppl community?”

Important:
Do not add major new features yet.
Do not build full native chat yet.
Do not build full marketplace functionality yet.
Do not overcomplicate the MVP.

The core MVP remains:
Apply → approve → become a member → access dashboard → view member access pass → RSVP to events → see perks → submit concierge request.
